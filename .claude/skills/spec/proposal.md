# proposal — 規劃方案

## 目的

針對使用者的問題去計劃要怎麼做，統一存放於 `@fastplan/plan`

## 作業流程

1. **理解與需求澄清**
   * 讀取使用者問題。
2. **搜集資料與思考判斷**
3. **輸出方案文件**
   * 在 `@fastplan/plan` 建立：`[提案簡稱]_plan.md`

## 命名規範
* **提案簡稱**：使用小寫、連字號，例：`task-refactor`、`onboarding-flow`。
* **路徑固定**：`@fastplan/plan/[提案簡稱]_plan.md`

## 使用語言

使用與使用者相同的語言即可
